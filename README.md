# Dragon Parade privacy policy

Public policy: https://florincor.github.io/dragon-parade-privacy/

GitHub Pages serves `index.html` from `main` at the repository root. `.nojekyll` disables Jekyll processing. The site has no JavaScript, external assets, analytics, forms, cookies or advertising.

`privacy-policy.txt` is the canonical text. The same file is bundled in the Android game's offline privacy dialog. In the game source workspace, update that text and run `python3 tools/prepare_privacy_policy.py` to regenerate the HTML. Deploy the resulting files here and rebuild the Android app when the policy changes.
